## 二、三阶段流程（Open / Build / Shape with AI）

```
┌──────────────────────────────────────────────────┐
│ 阶段 1：Open with AI（开源基础课程 / 初阶）          │
│   ├─ 学习项目基础课程                              │
│   ├─ 在线答题通关                                  │
│   └─ 获得：《开源研学结课证书》                     │

│   ├─ 认领并完成 issue                              │

│   └─ 获得：实践证书 + 腾讯精美周边                  │
├──────────────────────────────────────────────────┤

│   ├─ 筛选入围                                      │
```

**奖励规则（官网原文）**：
- 每个开源项目设有超 **3 万元** 奖金或礼品包

- 入围课题实战的 Top3 学生可获 **6000 / 8000 / 12000 元** 不等奖金
- 入围课题实战的同学可获腾讯优先面试机会

**AI 编程支持**：CodeBuddy、WorkBuddy 深度支持本次活动；入围"高阶"的同学可获 CodeBuddy/WorkBuddy 额外赠送的 token 资源。

## 三、14 个项目 × 9 大领域（官网原文分类）

> 原文：**"今年犀牛鸟面向全国高校学生及广大开发者发布 14 个实践项目，聚焦 AI 模型、开发框架、大前端、设计、数据库、编译器、操作系统、网络、安全等 9 大核心领域"**

### 3.1 14 个项目总览（按官网 9 大领域分组）

| # | 领域 | 项目 | 简介（一句话） | 仓库 |
|---|------|------|--------------|------|
| 1 | AI 模型 | 混元大语言模型（Hy3 preview） | 腾讯自研大语言模型 | Tencent/Hunyuan |
| 2 | AI 模型 | **YOLO-Master** | 革命性目标检测框架，整合 MoE/MoT/MoA 架构，CVPR 2026 论文 | [Tencent/YOLO-Master](https://github.com/Tencent/YOLO-Master) |
| 3 | AI 模型 | WeKnora | LLM 驱动的企业级文档理解与 RAG 框架 | Tencent/WeKnora |
| 4 | 开发框架 | **ncnn** | 移动端神经网络推理框架，C++ 实现，ARM NEON / Vulkan 加速 | [Tencent/ncnn](https://github.com/Tencent/ncnn) |
| 5 | 开发框架 | tRPC | 腾讯自研高性能 RPC 框架 | Tencent/trpc |
| 6 | 大前端 | KuiklyUI | 跨平台 UI 框架 | Tencent/KuiklyUI |
| 7 | 设计 | TDesign | 腾讯前端 / 设计 UI 组件库 | Tencent/TDesign |
| 8 | 数据库 | OpenTenBase | 分布式 HTAP 数据库（基于 PostgreSQL） | Tencent/OpenTenBase |
| 9 | 数据库 | TencentDB-Agent-Memory | 面向 AI Agent 的分层记忆引擎（2026-05 开源） | [Tencent/TencentDB-Agent-Memory](https://github.com/Tencent/TencentDB-Agent-Memory) |
| 10 | 编译器 | Tencent Kona JDK | Java 开发套件 | Tencent/TencentKonaJDK |
| 11 | 操作系统 | OpenCloudOS | 国产服务器操作系统 | Tencent/OpenCloudOS |
| 12 | 网络 | 腾讯高性能计算网络 | 面向 AI 的高性能网络栈 | Tencent/HPC-Network |
| 13 | 安全 | VulnGym | 漏洞演练平台 | Tencent/VulnGym |
| 14 | 安全 | CubeSandbox | 面向 AI Agent 的安全沙箱服务 | TencentCloud/CubeSandbox |

**校验**：9 领域 × 项目数 = AI 模型 (3) + 开发框架 (2) + 大前端 (1) + 设计 (1) + 数据库 (2) + 编译器 (1) + 操作系统 (1) + 网络 (1) + 安全 (2) = 14 ✓

### 3.2 按"是否与个人方向相关"做初步过滤

| 领域 | 项目 | 与目标检测/AI 推理相关性 | 备注 |
|------|------|-------------------------|------|
| AI 模型 | 混元大语言模型 | 低 | LLM，非 CV |
| AI 模型 | **YOLO-Master** | **高** | 目标检测 + MoE 架构 |
| AI 模型 | WeKnora | 低 | RAG 知识库 |
| 开发框架 | **ncnn** | **高** | 移动端推理，C++ 部署 |
| 开发框架 | tRPC | 低 | RPC 框架 |
| 大前端 | KuiklyUI | 无关 | UI 框架 |
| 设计 | TDesign | 无关 | UI 组件库 |
| 数据库 | OpenTenBase | 无关 | 分布式数据库 |
| 数据库 | TencentDB-Agent-Memory | 无关 | Agent 记忆引擎 |
| 编译器 | Tencent Kona JDK | 无关 | JDK |
| 操作系统 | OpenCloudOS | 无关 | 服务器 OS |
| 网络 | 腾讯高性能计算网络 | 弱 | 与 AI infra 相关但非 CV |
| 安全 | VulnGym | 无关 | 漏洞演练 |
| 安全 | CubeSandbox | 弱 | AI 沙箱，但非目标检测 |

**初步过滤结果**：14 → 2（YOLO-Master + ncnn），其余 12 个项目与个人方向（目标检测 + 边缘 AI 推理）不直接相关。

## 四、个人筛选过程（机械过滤 → 锁定 ncnn + YOLO-Master）

### 4.1 筛选条件

- **个人方向**：目标检测、模型部署、CVPR 2026 级别模型架构
- **个人技术栈**：C++ 部署经验 + 模型训练经验 + 8GB RTX 5060 显卡
- **个人目标**：大厂面试加分 + 读研科研经历

### 4.2 机械过滤步骤

```
14 个项目
   │
   ├─ 第 1 步：领域筛选 ── 排除非 AI 模型 / 非开发框架领域 12 个
   │                ── 保留 2 个：YOLO-Master（AI 模型）+ ncnn（开发框架）
   │
   ├─ 第 2 步：技术栈匹配 ── 两者均符合（C++ 部署 + 模型训练经验都覆盖）
   │
   ├─ 第 3 步：时间与硬件 ── 两者均符合（YOLO-Master 训练需要 8GB+ 显存，
   │                ncnn 部署 6GB 显存足够）
   │
   └─ 终选：2 个项目 ── 文档 02 进一步聚焦到具体 issue
```

### 4.3 不选其他 12 个项目的核心理由

| 项目 | 排除原因 |
|------|---------|
| 混元大语言模型 | LLM 方向，与目标检测不直接相关；显存需求 ≥ 24GB，个人硬件不够 |
| WeKnora | RAG / 文档理解方向，与 CV 无关 |
| tRPC | 后端 RPC 框架，与 AI 推理无直接关联 |
| KuiklyUI | 前端 UI 框架，与 AI 完全无关 |
| TDesign | UI 组件库，与 AI 完全无关 |
| OpenTenBase | 分布式数据库，需要 DBA / 内核背景 |
| TencentDB-Agent-Memory | Agent 记忆引擎，与 CV 无关 |
| Tencent Kona JDK | Java 编译器，与个人 C++ / Python 栈不匹配 |
| OpenCloudOS | 服务器操作系统，需要内核 / 系统编程背景 |
| 腾讯高性能计算网络 | 网络栈方向，与目标检测推理无关 |
| VulnGym | 漏洞演练，需要安全背景 |
| CubeSandbox | AI Agent 沙箱，虽与 AI 相关但是 Agent 方向而非 CV 推理 |

## 五、ncnn 与 YOLO-Master 详细对比

### 5.1 项目定位

| 维度 | ncnn | YOLO-Master |
|------|------|-------------|
| 所属领域 | 开发框架 | AI 模型 |
| 主要语言 | C++ | Python (PyTorch) + 部分 C++ |
| 核心技术 | ARM NEON、Vulkan 加速 | MoE / MoT / MoA 架构、ES-MoE |
| 论文 / 学术 | - | CVPR 2026 |
| 适合方向 | 模型部署、性能优化、边缘计算 | 目标检测、模型架构、模型训练 |
| 难度范围 | 中高 | 低 / 中高 |
| 犀牛鸟 issue 数 | 5（全部为模型移植） | 6（覆盖训练 / LoRA / 推理 / 剪枝 / 架构） |

### 5.2 两个项目解决的问题

- **ncnn** ：解决"训练好的模型如何高效部署到边缘设备（手机 / 嵌入式 / IoT）"
- **YOLO-Master** ：解决"如何设计更高效、更智能的目标检测模型架构（自适应计算）"

### 5.3 选择这两个项目的核心理由

- **ncnn**：C++ 部署是个人强项，可直接复用经验；边缘端推理是工业界核心技能
- **YOLO-Master**：CVPR 2026 论文级别，是读研方向（模型架构）的最佳实践项目；issue 类型多样，可分梯度选

### 5.4 两个项目都保留的理由

- 两个项目处于 AI 全链路关键位置（**模型设计** ↔ **模型部署**）
- 都有犀牛鸟专属 issue（中高级别）
- 个人技术栈（C++ 部署 + 模型训练）覆盖两个项目
- 选 issue 时可二选一，详见 `01-Issue汇总与简介.md`
