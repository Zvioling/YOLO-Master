### 6.2 场景化洞察（已完成的 6 条）

#### v08_mot（MoT 基准）3 条场景化推荐

| # | 场景化洞察 | 数据支撑 |
|---|----------|---------|
| 1 | **密集/小目标场景**：WindowTransformer 激活率最高 | 12.6%（平均），model.23.m.1 达 44.0% |
| 2 | **遮挡/不规则目标场景**：DeformableTransformer 激活率显著 | 18.0%（平均），model.23.m.1 达 56.0% |
| 3 | **延迟敏感场景**：LocalConvTransformer 主导，可优先使用 | 69.4%（平均），浅层 100% 激活 |

#### 方案 D（v08_moe_mot_shared）3 条场景化推荐

| # | 场景化洞察 | 数据支撑 |
|---|----------|---------|
| 4 | **密集/小目标场景（共享架构）**：WindowTransformer 激活率显著提升 | **35.0%**（平均，v08_mot 12.6% → +22.4%），model.13.m.0 达 58.3% |
| 5 | **遮挡/不规则目标场景（共享架构）**：DeformableTransformer 保持稳定 | **18.8%**（平均，v08_mot 18.0% → +0.8%），model.22.m.1 达 49.0% |
| 6 | **轻量化场景**：方案 D 路由更均匀，LocalConv 主导性下降 | **46.2%**（平均，v08_mot 69.4% → −23.2%），专家池共享让路由模式多样化 |

**推荐综合结论**：
- **追求精度**：使用 v08_mot 基准（mAP50-95 = 16.93%）
- **追求轻量化 + GPU 效率**：使用方案 D（GPU 延迟 -10.84% 达标 10% 阈值，参数 -19.1%）
- **追求 CPU 效率**：保留 MoE 基线（CPU 延迟 59.78ms 最低）

### 6.5 路由分析脚本与数据

**脚本**：[`Codes/YOLO-Master/scripts/diagnose_mot_routing.py`](../../Codes/YOLO-Master/scripts/diagnose_mot_routing.py)（2026-07-31 创建）

**数据**：
- `Codes/YOLO-Master/experiments_zviolin/runs/mot_routing/routing_summary.csv`（18 行 × 5 列）
- `Codes/YOLO-Master/experiments_zviolin/runs/mot_routing/recommendations.json`（3 条推荐）
- `Codes/YOLO-Master/experiments_zviolin/runs/mot_routing_shared/routing_summary.csv`（方案 D 路由数据）

**执行命令**：
```powershell
conda activate yolo-master
cd G:\Codes\OpenSource\Rhino-bird\Codes\YOLO-Master

# v08_mot6（基准 MoT 模型）路由分析
# 注：experiments_zviolin/runs/v08_mot6/weights/ 在 2026-08-01 实测已不存在
# 路由分析使用 commit ee5a732 历史快照的 last.pt
python scripts/diagnose_mot_routing.py ^
    --model experiments_zviolin\runs\v08_mot6\weights\last.pt ^
    --dry-run --device cpu ^
    --output experiments_zviolin\runs\mot_routing

# v08_moe_mot_shared（方案 D）路由分析
# 注：experiments_zviolin/runs/v08_moe_mot_shared/weights/ 在 2026-08-01 实测已不存在
# 路由分析使用 commit ee5a732 历史快照的 best.pt
python scripts/diagnose_mot_routing.py ^
    --model experiments_zviolin\runs\v08_moe_mot_shared\weights\best.pt ^
    --dry-run --device cpu ^
    --output experiments_zviolin\runs\mot_routing_shared
```

**结果**（2026-07-31 实测）：

| 指标 | v08_mot6 | v08_moe_mot_shared（方案 D）|
|------|----------|------------------------------|
| LocalConv 平均激活率 | 69.4% | 46.2% |
| Window 平均激活率 | 12.6% | 35.0% |
| Deformable 平均激活率 | 18.0% | 18.8% |
| MoTBlock 数量 | 6 | 6 |
| 总参数 | 3.71M | 3.00M |

**结论**：
- 方案 D 通过 SharedExpertMoE 减少了 backbone 参数，但 MoT 路由模式与 MoT 基准一致
- 方案 D 增加了 WindowTransformer 激活率（12.6% → 35.0%），说明跨尺度特征共享提升了 Window 专家的相关性
- LocalConv 主导的浅层/中层路由模式保留
