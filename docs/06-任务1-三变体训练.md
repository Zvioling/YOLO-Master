### 1.0 任务原文（Issue #54 原文）

> 在 COCO 或 VisDrone 数据集上，使用 scripts/compare_mot_ablation.py 作为参考脚本，训练至少 3 种模型变体：YOLO-Master-EsMoE-N（MoE 基线）、YOLO-Master-v0.10-MoT-N（MoT 实验模块）、YOLO-Master-v0.10-MoA-N（MoA 对比组）

### 1.1 任务介绍

本任务是 Issue #54 的基础，需要在 VisDrone 数据集上训练 3 种模型变体：

| 变体 | 配置文件 | 参数量 | 训练目标 |
|------|---------|--------|---------|
| MoE 基线 (YOLO-Master-EsMoE-N) | `yolo-master-n.yaml` | ~3.14M | 提供基线参考 |
| MoT 变体 (YOLO-Master-v0.10-MoT-N) | `yolo-master-mot-n.yaml` | ~3.71M | 验证 MoT 架构 |
| MoA 对比 (YOLO-Master-v0.10-MoA-N) | `yolo-master-moa-n.yaml` | ~3.23M | 与 MoT 对比 |

**训练配置**：batch=8, imgsz=640, epochs=100, device=0（RTX 5060 8GB）

### 1.2 实验步骤（命令行 + 终端输出 + 汇总说明）

> **目录命名约定**：`compare_mot_ablation.py` 中 `model.train(name=spec.key)` 会按 spec.key 创建输出目录（`v08`、`v08_mot`、`v08_moa`），但若目标目录已存在，ultralytics 会自动追加数字后缀（`v084`、`v08_mot6`、`v08_moa2`）。**本任务的实际训练输出目录**为带数字后缀的版本（`v084/`、`v08_mot6/`、`v08_moa2/`），原因是多次实验运行累积。运行前请先在 `runs/mot_ablation/` 下确认目录命名。

**目标**：训练 YOLO-Master-EsMoE-N 基线模型

**命令行**：

### 步骤 4：训练中断恢复命令

**目标**：训练因意外中断时恢复

**前提条件**：
- 实际训练输出目录为 `v084`、`v08_mot6`、`v08_moa2`（ultralytics 默认在目录冲突时自动添加数字后缀）
- 2026-08-01 实测：`v084/`、`v08_mot6/`、`v08_moa2/` 三个目录**均不包含 `weights/` 子目录**（仅 `args.yaml` 和 `results.csv`），weight 文件未随实验仓库保存
- `summary.csv` 中的 v08/v08_mot/v08_moa 数据来自 spec key 替身目录（手动复制 results.csv 后通过 `--summary-only` 生成）

**历史训练恢复（需先获取 weights）**：
```powershell
# 1. 若有保存的 weight 文件，按以下命名放回 weights/ 目录
# runs/mot_ablation/v084/weights/last.pt
# runs/mot_ablation/v08_mot6/weights/last.pt
# runs/mot_ablation/v08_moa2/weights/last.pt

# 2. 恢复训练命令
python -c "from ultralytics import YOLO; YOLO(r'runs\mot_ablation\v084\weights\last.pt').train(resume=True)"
python -c "from ultralytics import YOLO; YOLO(r'runs\mot_ablation\v08_mot6\weights\last.pt').train(resume=True)"
python -c "from ultralytics import YOLO; YOLO(r'runs\mot_ablation\v08_moa2\weights\last.pt').train(resume=True)"
```

**新训练恢复（如未来需重训，可使用 spec key 目录名）**：
```powershell
# 按步骤 1-3 重新训练时，目录名以 v08/v08_mot/v08_moa 起始
# 若 v08 目录已存在，ultralytics 会自动递增为 v08N 目录
# 恢复训练命令（以 v08 为例）：
python -c "from ultralytics import YOLO; YOLO(r'runs\mot_ablation\v08\weights\last.pt').train(resume=True)"
```

**汇总说明**：
- `resume=True` 自动从 `args.yaml` 读取原始配置（batch、imgsz、device）
- 无需重复指定训练参数
- 适用于 KeyboardInterrupt、断电等意外中断
- **重要**：当前 `v084`/`v08_mot6`/`v08_moa2` 目录下没有 `weights/` 子目录（2026-08-01 实测），如需使用这些目录的 weight 文件需重新训练

### 1.3 训练结果汇总

### 1.5 关键观察

1. **MoT 变体 mAP50-95 最高**（16.93%），比 MoE 基线高 0.09%
2. **MoT 训练时间最长**（19.5h），比 MoE 基线慢 1.47 倍
3. **MoA 变体训练最快**（10.9h），Precision 最高（40.75%）
4. **三变体性能差距极小**（mAP50-95 差距 < 0.15%）
5. **所有变体训练稳定**，无 NaN
6. **所有变体均完整跑完 100 个 epoch**（无提前停止）
