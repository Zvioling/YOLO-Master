### 1.0 任务原文（Issue #54 原文）

> 在 COCO 或 VisDrone 数据集上，使用 scripts/compare_mot_ablation.py 作为参考脚本，训练至少 3 种模型变体：YOLO-Master-EsMoE-N（MoE 基线）、YOLO-Master-v0.10-MoT-N（MoT 实验模块）、YOLO-Master-v0.10-MoA-N（MoA 对比组）

### 1.1 任务介绍

本任务是 Issue #54 的基础，需要在 VisDrone 数据集上训练 3 种模型变体：

| 变体 | 配置文件 | 参数量 | 训练目标 |
|------|---------|--------|---------|
| MoE 基线 (YOLO-Master-EsMoE-N) | `yolo-master-n.yaml` | ~3.14M | 提供基线参考 |
| MoT 变体 (YOLO-Master-v0.10-MoT-N) | `yolo-master-mot-n.yaml` | ~3.71M | 验证 MoT 架构 |
| MoA 对比 (YOLO-Master-v0.10-MoA-N) | `yolo-master-moa-n.yaml` | ~3.23M | 与 MoT 对比 |

**训练配置**：batch=8, imgsz=640, epochs=100, device=0（RTX 5060 8GB）

### 1.2 实验步骤（命令行 + 终端输出 + 汇总说明）

> **目录命名约定**：`compare_mot_ablation.py` 中 `model.train(name=spec.key)`，故运行后输出目录为 `runs/mot_ablation/{spec.key}/`。本任务中已有的目录是带数字后缀的旧版本（`v084`、`v08_mot6`、`v08_moa2`），但实际训练输出目录名为 `v08`、`v08_mot`、`v08_moa`。运行命令前请先在 `runs/mot_ablation/` 下确认目录命名。

**目标**：训练 YOLO-Master-EsMoE-N 基线模型

### 步骤 4：训练中断恢复命令

**目标**：训练因意外中断时恢复

**前提条件**：
- 当前 `runs/mot_ablation/` 下存在带数字后缀的目录 `v084`、`v08_mot6`、`v08_moa2`（仅含 `args.yaml` 和 `results.csv`）
- `v08_mot6/weights/` 包含 `best.pt` 和 `last.pt`（各 7,945,065 字节，2026/7/27 21:27:12），可用于直接恢复训练
- 若按本任务步骤 1-3 重新训练，新输出目录为 `v08`、`v08_mot`、`v08_moa`，且会自动生成 `weights/last.pt`，可用以下恢复命令

**命令行（新训练后恢复用）**：
```powershell
# 恢复 MoE 基线（从 v08 继续，需要先按步骤 1 训练）
python -c "from ultralytics import YOLO; YOLO(r'runs\mot_ablation\v08\weights\last.pt').train(resume=True)"

# 恢复 MoT 变体（从 v08_mot 继续，需要先按步骤 2 训练）
python -c "from ultralytics import YOLO; YOLO(r'runs\mot_ablation\v08_mot\weights\last.pt').train(resume=True)"

# 恢复 MoA 变体（从 v08_moa 继续，需要先按步骤 3 训练）
python -c "from ultralytics import YOLO; YOLO(r'runs\mot_ablation\v08_moa\weights\last.pt').train(resume=True)"
```

**历史训练目录恢复（仅在对应目录有 weights 子目录时可用）**：
```powershell
# 若历史目录 v084/v08_mot6/v08_moa2 中已有 weights/last.pt，可用以下命令
python -c "from ultralytics import YOLO; YOLO(r'runs\mot_ablation\v084\weights\last.pt').train(resume=True)"
python -c "from ultralytics import YOLO; YOLO(r'runs\mot_ablation\v08_mot6\weights\last.pt').train(resume=True)"
python -c "from ultralytics import YOLO; YOLO(r'runs\mot_ablation\v08_moa2\weights\last.pt').train(resume=True)"
```

### 1.3 训练结果汇总

> **说明**：本表中的实际数据来自 `runs/mot_ablation/v084/results.csv`、`v08_mot6/results.csv`、`v08_moa2/results.csv` 的最后一行（epoch 100）。这些目录是历史训练输出（带数字后缀），实际训练完整跑完 100 个 epoch。

| 变体 | 训练 Epochs | 训练时长 | 最终 mAP50-95 | 最终 mAP50 | Precision | Recall | 输出目录 |
|------|------------|----------|--------------|-----------|-----------|--------|---------|
| MoE 基线 (v084) | 100/100 | 47,813s (13.3h) | 16.84% | 29.79% | 39.47% | 31.05% | `runs/mot_ablation/v084/` |
| MoT 变体 (v08_mot6) | 100/100 | 70,272s (19.5h) | **16.93%** | 29.77% | 39.37% | **31.22%** | `runs/mot_ablation/v08_mot6/` |
| MoA 变体 (v08_moa2) | 100/100 | 39,211s (10.9h) | 16.80% | 29.55% | **40.75%** | 30.04% | `runs/mot_ablation/v08_moa2/` |

### 1.4 训练稳定性分析

| 变体 | Loss 收敛 | NaN | 备注 |
|------|----------|-----|------|
| MoE 基线 | ✅ 正常收敛 | ❌ 无 | moe_loss 从 0.187 降至 0 |
| MoT 变体 | ✅ 正常收敛 | ❌ 无 | moe_loss 从 0.328 降至 0，训练较慢 |
| MoA 变体 | ✅ 正常收敛 | ❌ 无 | moe_loss 从 0.187 降至 0，训练最快 |

### 1.5 关键观察

1. **MoT 变体 mAP50-95 最高**（16.93%），比 MoE 基线高 0.09%
2. **MoT 训练时间最长**（19.5h），比 MoE 基线慢 1.47 倍
3. **MoA 变体训练最快**（10.9h），Precision 最高（40.75%）
4. **三变体性能差距极小**（mAP50-95 差距 < 0.15%）
5. **所有变体训练稳定**，无 NaN
