```powershell

# 2. 验证环境
python -c "import torch; print(f'PyTorch: {torch.__version__}, CUDA: {torch.cuda.is_available()}')"

cd g:\Codes\OpenSource\Rhino-bird\Codes\YOLO-Master
```

## 七、注意事项

### 7.1 设备使用

- 训练期间保持电源连接
- 监控显存使用，避免 OOM
- 使用外部散热设备防止过热

### 7.2 代码规范

- 使用 4 空格缩进
- 函数命名使用 snake_case
- 类命名使用 PascalCase
- 常量使用 UPPER_SNAKE_CASE
- 文件命名使用 kebab-case

### 7.3 提交规范

- 提交信息使用中文
- 格式：`type: description`
- 类型：feat, fix, docs, style, refactor, test, chore
- 示例：`feat: 添加 MoT 路由分析可视化`

### 7.4 安全事项

- 不执行危险命令
- 数据库操作前确认
- 不在版本控制中保存敏感信息
- 使用环境变量管理 API 密钥
