> **评级标准**:
> - **创新性 ★** = 0(纯调用)/ 1(包装组合)/ 2(算法级贡献)/ 3(方法论贡献)
> - **重要性 ⚑** = 必做(放弃则任务无法推进)/ 应做(评审加分)/ 锦上添花(可选)
> - **本质** = 一句话说明它在 F11 中起什么作用

## 四、任务 T2:q_teacher 构造(P0/P1)

### 4.1 子任务拆分

| 子任务            | 动作                                              | 验收点             |
| ----------------- | ------------------------------------------------- | ------------------ |
| T2.1 专家输出提取 | 训练期对单路由层 2 专家前向,记录 E_0(x), E_1(x)   | shape (B, N, C)    |

| T2.4 平滑混合     | ε-uniform 混合:q = (1-ε)q_teacher + ε·uniform | 防止单专家坍塌     |

### 4.2 q_teacher 数学定义

```
logit_i(x) = <E_i(x), T(x)> / (||E_i|| · ||T||)     # 余弦相似
mask       = 1{T_norm > τ_mask}                     # 置信度掩码
q_teacher  = softmax(logit / τ + log(mask))
q_teacher  = (1-ε) q_teacher + ε · uniform(E)        # 平滑
```

| 参数              | 默认 | 搜索空间         |
| ----------------- | ---- | ---------------- |
| τ(温度)          | 1.0  | {0.5, 1.0, 2.0}  |
| ε(平滑)          | 0.1  | {0.05, 0.1, 0.2} |
| τ_mask(掩码阈值) | 0.0  | {0.0, 0.5, 1.0}  |

> **⚠️ 2026-09-07 修复注记(2026-09-12 按磁盘实证修订)**:上表 τ=1.0 / ε=0.1 是**负结果根因**(教师软目标近均匀,KD 无信号),smoke 侧已按 **τ=0.5 / ε=0.0** 修复验证(H_norm=**0.7022**,pass:true,原始 json 摘录见 08b §A.3)。**real T2R(8/26)实际执行 τ=1.0 / ε=0.1**(report.json 现存为证),H_norm=0.8385:非坍塌 100% PASS、非均匀 89.9% 距 90% 阈差 0.1pp(真原型分布偏均匀属预期,H 维度按判读线 [0.3, 1.0] 合格);**q_teacher.pt 未重新生成**,quick500_v2 直接复用该软目标——9/8-9/9 修复的是**训练侧**(KD 挂载接口 modules 0→3 + `router_temperature 1.0→0.5` + `router_loss_weight 0.5`),实测 JS=0.0146 证明该软目标在修复后的训练侧参数下传递有效(机制 5/5 PASS)。

### 5.2 损失函数设计

```python
# ultralytics/nn/loss/router_kd.py
class RouterKDLoss(nn.Module):
    def __init__(self, temperature=1.0, smoothing=0.1, kind='js'):
        super().__init__()
        self.tau = temperature
        self.eps = smoothing
        self.kind = kind
  
    def forward(self, q_student, q_teacher):
        # 平滑
        E = q_teacher.shape[-1]
        q_teacher = (1 - self.eps) * q_teacher + self.eps / E
        # 温度软化
        q_student = F.softmax(q_student / self.tau, dim=-1)
        # JS / KL
        if self.kind == 'js':
            m = 0.5 * (q_student + q_teacher)
            return 0.5 * (F.kl_div(q_student.log(), m, reduction='batchmean')
                       + F.kl_div(q_teacher.log(), m, reduction='batchmean'))
        else:
            return F.kl_div(q_student.log(), q_teacher, reduction='batchmean')
```

### 5.3 总损失与 λ warmup

```
L_total = L_task + λ(t) · L_router_kd
λ(t) = clip(t / 5, 0, 1) · λ_max    # 5 epoch warmup
λ_max = 0.5                          # 默认
```

### 10.2 负向判据(任务书 §1 实验红线)

| 情况           | 触发                       | 处理                           |
| -------------- | -------------------------- | ------------------------------ |
| mAP 显著掉点   | C vs A\|ΔmAP\| > 0.5%     | 检查 λ/温度/对齐              |
| CI 含 0        | \|ΔmAP\| < 0.3 且 CI 含 0 | **no-go**,转向相关性审计 |
| q_teacher 退化 | H_norm ∈ {0, 1}           | 调 τ/ε/掩码                  |
| 路由坍塌       | 单专家 > 90%               | 共享投影 + λ warmup           |
| 训练不稳       | loss 震荡                  | λ 调小 + warmup 延长          |
