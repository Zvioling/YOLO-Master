## 四、任务 T2:q_teacher 构造(P0/P1)

### 4.1 子任务拆分

| 子任务 | 动作 | 验收点 |
|--------|------|--------|
| T2.1 专家输出提取 | 训练期对单路由层 2 专家前向,记录 E_0(x), E_1(x) | shape (B, N, C) |
| T2.2 一致性度量 | 计算 cos_sim(E_i, T) / L2 距离 → logit | logit shape (B, 2) |
| T2.3 温度 + 掩码 | 应用 τ / 置信度掩码(剔除 L2 范数 < τ 的 patch)| 输出 softmax 分布 |
| T2.4 平滑混合 | ε-uniform 混合:q = (1-ε)q_teacher + ε·uniform | 防止单专家坍塌 |
| T2.5 熵验证 | 打印 H_norm ∈ (0.3, 0.8) | 日志记录 |
| T2.6 单专家检查 | 任何单专家选中率 < 90% | 分布直方图 |

### 4.2 q_teacher 数学定义

```
logit_i(x) = <E_i(x), T(x)> / (||E_i|| · ||T||)     # 余弦相似
mask       = 1{T_norm > τ_mask}                     # 置信度掩码
q_teacher  = softmax(logit / τ + log(mask))
q_teacher  = (1-ε) q_teacher + ε · uniform(E)        # 平滑
```

| 参数 | 默认 | 搜索空间 |
|------|------|----------|
| τ(温度)| 1.0 | {0.5, 1.0, 2.0} |
| ε(平滑)| 0.1 | {0.05, 0.1, 0.2} |
| τ_mask(掩码阈值)| 0.0 | {0.0, 0.5, 1.0} |

### 4.3 验证三件事

1. **熵非退化**:H_norm(q_teacher) ∈ (0.3, 0.8);不可 0(单专家坍塌)或 1(完全均匀)
2. **非单专家坍塌**:max(q) < 0.9 across batch
3. **样本间有差异**:top-1 选择切换率 ∈ (0.2, 0.8);不可全相同

### 4.4 复现命令

```powershell
python scripts/gen_q_teacher.py \
  --cache runs/f11_teacher_cache \
  --model yolo-master-n.yaml \
  --layers 8 --experts 2 \
  --temperature 1.0 --smoothing 0.1 \
  --out runs/f11_q_teacher/
```

### 4.5 验收点

- [ ] H_norm ∈ (0.3, 0.8) 且稳定(±0.1 across batch)

### 5.2 损失函数设计

```python
# ultralytics/nn/loss/router_kd.py
class RouterKDLoss(nn.Module):
    def __init__(self, temperature=1.0, smoothing=0.1, kind='js'):
        super().__init__()
        self.tau = temperature
        self.eps = smoothing
        self.kind = kind
    
    def forward(self, q_student, q_teacher):
        # 平滑
        E = q_teacher.shape[-1]
        q_teacher = (1 - self.eps) * q_teacher + self.eps / E
        # 温度软化
        q_student = F.softmax(q_student / self.tau, dim=-1)
        # JS / KL
        if self.kind == 'js':
            m = 0.5 * (q_student + q_teacher)
            return 0.5 * (F.kl_div(q_student.log(), m, reduction='batchmean')
                       + F.kl_div(q_teacher.log(), m, reduction='batchmean'))
        else:
            return F.kl_div(q_student.log(), q_teacher, reduction='batchmean')
```

### 5.3 总损失与 λ warmup

```
L_total = L_task + λ(t) · L_router_kd
λ(t) = clip(t / 5, 0, 1) · λ_max    # 5 epoch warmup
λ_max = 0.5                          # 默认
```
