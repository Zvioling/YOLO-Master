## T6R.4 教师对比实测(2026-09-10 · DINOv2 vs SigLIP2,quick 同预算)

> **设计**:DINOv3 为 Meta gated 模型(镜像不可用),修正为 **DINOv2 vs SigLIP2**——`facebook/dinov2-base` 非 gated 公开权重(346MB,落盘 HF 缓存 + `DATASETS\foundation_teachers\dinov2-base\`),`DINOv2Teacher` 已接入框架。同预算:500 张 × 10ep × batch 8 × τ=0.5 × seed 0,唯一变量为教师。

**配套代码修复**:

| # | 位置 | 修复 |
|---|---|---|
| ① | `scripts/compare_f11_ablation.py` | `--teacher` 切换时映射目标教师默认 model_id(`TEACHER_DEFAULT_MODELS`) |
| ② | `ultralytics/nn/foundation_distill_model.py` | 补 `DEFAULT_DINOV2_MODEL`/`DINOv2Teacher` import + 教师分支 |

**命令**(log: `experiments/f11_real_baseline/logs/quick_validate/t6/T6R_4_{dinov2,siglip2}_20260910_*.log`):

```powershell
python scripts/compare_f11_ablation.py --train --groups c --teacher dinov2 --name c-router-kd-dinov2 --router-temperature 0.5 --epochs 10 --imgsz 640 --batch 8 --workers 8 --device 0 --data "G:\Codes\OpenSource\Rhino-bird\DATASETS\VisDrone_500.yaml" --project runs/quick500_v2/t6_extension/teacher_compare 2>&1 | Tee-Object -FilePath "experiments\f11_real_baseline\logs\quick_validate\t6\T6R_4_dinov2_$TS.log"
# siglip2 侧同参数:--teacher siglip2 --name c-router-kd-siglip2
```

**KD 生效铁证**(results.csv):

| 判据 | DINOv2 | SigLIP2 |
|---|---|---|
| foundation_router_modules | 3(全程) | 3(全程) |
| router_loss ep1→ep10 | 0.1144→0.0914 | 0.0932→**0.0668** |
| router_kl 非零 | ✓ | ✓ |
| teacher_entropy | ≈2.0015 | ≈1.9977 |

**结果对比**:

| 指标 | DINOv2 | SigLIP2 | 判读 |
|---|---|---|---|
| mAP50-95 @ep10(last) | 0.00323 | 0.00329 | 差 0.006 个百分点,噪声区内无可分辨差异 |
| mAP50 @ep10(last) | 0.01108 | 0.01200 | 同上 |
| 每 epoch 耗时 | ~478s(ep9→10 实测 477.8s) | **~215s**(ep9→10 实测 215.7s) | SigLIP2 教师开销减半 |
| lr 曲线 | 同 seed=0 逐 epoch 一致 | 同 | 严格同预算,唯一变量为教师 |

**结论**:

1. 两个教师都能驱动 Router KD 生效(铁证见上表);
2. quick 同预算下 mAP 无可分辨差异 → **教师选择不是 KD 生效性的敏感变量**;
3. SigLIP2 软目标更紧(熵更低、KL 收敛更快)且训练开销减半 → **全量 C 组维持 siglip2 教师**;
4. T6R.4 以 quick 同预算收口(满足任务书"比较教师,**或**分析负结果"的"比较教师"分支),全量教师对比不再追加。
