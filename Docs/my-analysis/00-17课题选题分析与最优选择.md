## 五、第四关：研究叙事连续性 + 论文潜力 + 确定性 → 终选

### 5.1 关键判断：Zviolin 的"科研资产"是一条完整叙事链

上一轮 Issue #54 已经完成**"MoT 架构 → 路由行为分析"** 两个研究环节（热力图、熵、场景化洞察、合成/真实对比）。
新课题里只有 **F11（Foundation 路由 KD）** 能把这个叙事**自然延伸**到第三个环节：

```
#54 已完成：MoT 三变体消融（架构是什么）
    ↓
#54 已完成：路由可解释性（路由行为如何，为什么）
    ↓
F11 新课题：Foundation 路由 KD（如何用教师信号塑造更好的路由）
```

F11 的交付物（`路由 KD 设计文档`、`q_teacher 生成`、`三方同预算对照`、`路由熵/负载分析`）
几乎全部建立在 Zviolin 已掌握的技能上：hook 提路由、熵计算、诊断脚本、低资源训练、8GB 特征缓存。

### 5.2 终选：F11 Foundation 路由 KD（主选）

| 维度 | 判断 |
|------|------|
| **为什么是 F11** | 1) 研究叙事唯一可延续 #54 的课题，论文故事完整（可写 "从 MoT 消融到路由蒸馏"）；2) 任务书标注"探索型｜高研究价值"，允许负结果但要求证据链，风险有兜底；3) P0 门槛可及（单路由层、2 专家小配置 + 100 张特征缓存，8GB 可做最小验证）|
| **算力可行性** | 教师特征**离线缓存**（任务书明示"优先离线缓存"），训练期教师可移除 → 8GB 只跑学生 Router 训练，与 #54 三变体训练同量级（已在 8GB 验证过）|
| **与 E3 协作** | 任务书 §3：E3 → F11 供给"路由 schema、snapshot、热图"——选 E3 组协作或自己做 E3 工具均受益 |
| **风险与降级** | 教师软目标退化 → 调温度/平滑/置信度掩码；方法无效 → 降级为"教师语义结构与现有路由相关性审计"（保留量化证据，仍可交差）|
| **论文潜力** | 任务书 P2：多层/MoT 扩展、小样本/跨域泛化、DINOv2/v3 教师对比 → 完整的机制分析论文材料 |

**F11 P0 准入目标（8.24 检查项）**：
- [ ] 100 张图教师特征缓存可复现（COCO mini 起步）
- [ ] 单 batch 生成 q_teacher，熵不接近 0 且非均匀常数
- [ ] Router KD 梯度非零（`collect_aux_loss` 白名单注册验证）
- [ ] 提交训练命令 + loss 日志 + 路由分布图 + 显存估算

### 5.3 备选：E3 五族混合系统的路由透视镜

| 维度 | 判断 |
|------|------|
| **为什么是 E3** | 1) **确定性最高**：任务书"工具型｜推荐｜低算力｜1–2 人"；2) `diagnose_mot_routing.py`（240 行）几乎可直接升级为 E3 工具（P0：统一 schema + MoE/MoT/Latent 三类结构化日志）——**两周内可交付 P0**；3) P2（token 路由热图叠加原图）与已有热力图工作一脉相承 |
| **价值** | E3 是任务书 §3 协作网络的核心供给方（→ B1/D1/F11/A3/F1），做成后是全组公共基础设施，PR 价值高、答辩故事好 |
| **风险** | 几乎没有（低算力 + 技能直接复用）|

### 5.4 稳健降级：A2 STAL 小目标自适应标签分配

| 维度 | 判断 |
|------|------|
| **为什么是 A2** | 1) **VisDrone 数据集与训练配方完全现成**（#54 三个变体都在 VisDrone 上训练过 100 epoch）；2) "稳健研究｜推荐｜中算力｜1–2 人"；3) P1 判读线清晰（小目标 AP 提升 ≥1.0 且非噪声），确定性高 |
| **联动价值** | 任务书 §3：A2 → C1（STAL 是擂台合法武器），可反向为 C1 组提供实现 |
| **风险** | 稳健但创新性中等，论文潜力低于 F11 |

### 5.5 为什么不选 A3 / C1（同分靠后者的说明）

| 课题 | 不选原因 |
|------|---------|
| **A3 Export Gap** | 有价值（部署 + 量化），但建议团队 2–3 人；且 Zviolin 无 TensorRT 环境，P1 要求"两类路由 INT8 PTQ"只能降级 ONNX Runtime 声明，完成度受限；与 F11 相比研究叙事较弱 |
| **C1 VisDrone 擂台** | 数据与武器现成是优势，但需要**组队 2–3 人 + 周更榜单 + 多 seed 决赛**，单人启动压力大；若 8.21–8.24 能找到 1–2 名队友，C1 可作并列备选 |
