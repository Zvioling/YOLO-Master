## 6.2 real 全量 与 quick500_v2 的贡献分工(P0/P1/P2 × 两套数据)

| 目标档 | **real 全量**(VisDrone 6471 张 × 100ep)| **quick500_v2**(VisDrone-500 × 100ep × A/B/C 同预算)|
|--------|---------------------------------------|------------------------------------------------------|
| **P0 保底** | ✅ **全部由 real 完成**:T0R 数据准备 + T1R 200 patch 教师缓存 + T2R 真 q_teacher[51200,4] + T3R 真 Router KD 双复跑 100ep PASS(KD=0.0141/0.0150,grad 0.0296/0.0267) | 直接复用 real 的 T1R/T2R 产物作为蒸馏输入 |
| **P1 预期** | ✅ **real 尺度 A/B**:a-baseline(6 份)与 b-repr-kd 各 100ep,mAP50-95 均为 **0.1695**(repr-KD 生效但信号弱,KD 项占损 0.72%)——证明 real 尺度下表征 KD 无增益,且给出任务级基线 | ✅ **核心对照**:A/B/C **严格同预算**三方 100ep + T5R 路由分析(switch 0→0.3636 / load_std -33%)+ 学生零教师部署全绿 |
| **P2 理想** | —(T6R.1/2 因配置问题无有效数据,已定性;T6R.3 协议落盘) | ✅ **全部**:T6R.4 教师对比收口(DINOv2 vs SigLIP2 → 维持 siglip2)+ T6R.5 机制分析 **5/5 PASS(KD 有效)** |
| **全量 C 组** | ⏸ 重跑暂停(需 ~3 天,恢复命令见 07c 置顶节) | — |

> **一句话分工**:**P0 由 real 打底,P1 由 real(A/B 基线) + quick(C 组核心对照)共同完成,P2 由 quick 完成**——两套数据互补:real 提供任务级基线与真实数据链路,quick 提供严格同预算的 KD 有效性证据(机制 5/5 PASS)。

## 6.3 核心结论

1. **P0+P1+P2 全部达成**(分工见 §6.2):real 全量完成 P0 全部 + P1 的 A/B 基线;quick500_v2 完成 P1 的三方同预算对照 + T5R + P2 全部;
2. **KD 有效(机制 5/5 PASS)**:软目标 JS=0.0146 / 路由切换 0→0.3636 / 负载均衡改善 33% / 无坍塌;mAP 持平(Δ=-0.0001,噪声内,不作显著性结论);
3. **教师对比收口**:DINOv2 vs SigLIP2 均 KD 生效,SigLIP2 软目标更紧且开销减半 → 维持 siglip2;
4. **repr-KD(B 组)信号弱**:KD 项仅占总损失 0.72%,无增益 —— 这是 C 组转向 router KD(权重 5 倍)的设计依据;
5. **零教师部署成立**:Foundation/Teacher Router 残留=0,冻结参数=0,P50=35.94ms;
6. **全量 C 组暂停**:重跑需 ~3 天无法在 9.14 前完成,恢复命令见 07c 置顶节。
