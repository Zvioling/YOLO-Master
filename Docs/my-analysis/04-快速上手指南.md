## 五、常见问题

| 问题 | 解决 |
|------|------|
| 8GB OOM | batch 8→4/2;imgsz 640→512;教师特征离线分片缓存;C 组(KD)实测稳态 batch=8 |
| Windows 显存不足不报错、系统内存暴涨 | NVIDIA 驱动 CUDA Sysmem Fallback 在把显存溢出到内存——立即停训,降 batch |
| `collect_aux_loss` 不生效 | 新增 distill kind 必须显式注册,单测证明进入总 loss |
| HuggingFace 下载 timeout | `$env:HF_HUB_OFFLINE = "1"`(训练走本地缓存);下载用 hf-mirror |
| KD 无效(router_loss 恒 0) | 确认 `foundation_router_modules=3` 出现在训练 log(路由模块全家族挂载)+ τ=0.5 |
